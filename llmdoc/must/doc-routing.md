# Documentation Routing

- Project identity and scope: `llmdoc/overview/`.
- Runtime ownership, flows and trust boundaries: `llmdoc/architecture/`.
- Repeatable implementation and validation steps: `llmdoc/guides/`.
- Exact workflow inputs, permissions, models, artifacts and schemas: `llmdoc/reference/`.
- Durable choices: `llmdoc/memory/decisions/`.
- Mistakes and reusable lessons: `llmdoc/memory/reflections/`.
- Temporary investigation belongs only in ignored `.llmdoc-tmp/investigations/`.
